A module prints a fast loop for a `sum`, a `mean`, a `min` or a `max` over all the records. Its term must read the record only through columns of the run. The body of each call of the term is at the place of the call. Each read of a column reads its pack: an array of the values of the column, which the first such loop of a run makes. One try covers all the items. The values and the errors do not change. The other list ops print the code of the version before.
