The new package `@mark1russell7/vex-mcp` is the MCP server of Vex. Its tools give the catalog of the domains (`vex_catalog`), and they check (`vex_check`), evaluate (`vex_evaluate`), explain (`vex_explain`) and compile (`vex_module`) a program as JSON. The command `vex-mcp` starts the server on the standard input and output. The plugin of Vex for Claude Code starts it.
