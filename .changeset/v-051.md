V-051: The address of the axis `all` can fail at some keys. The memo of tier 2 took a list op over such an axis as a value of the space, so tier 2 gave the value of the first key at each key. Now only an address that depends on no key keeps the list op in the memo, and a standalone module evaluates the address too.
