# Changesets

A changeset records a change to a published package and the version step that it needs. To add one, start `pnpm changeset` and answer the questions. The release workflow reads the changesets, sets the versions and writes the change logs.

The four packages `@mark1russell7/vex`, `@mark1russell7/vex-domains`, `@mark1russell7/vex-testkit` and `@mark1russell7/vex-compiler` have one version together.
