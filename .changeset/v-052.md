V-052: A move from the focus can fail before a fixed key, an index or the origin, for example `[offset(1), key("0")]` at the last key. The memo of tier 2 took such an address as a fixed key, so tier 2 gave the value of another key. A standalone module kept only the code of the last move. Now the address reads its start, and a module keeps the check of each move that can fail.
