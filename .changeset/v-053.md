V-053: A node with a tag that the version does not know made `compile` throw a `TypeError`, for example a program with `fold` in 0.6.0. Now `compile`, `evaluate` and a sheet check the shape of the expression first (EVAL.SHAPE). An expression that is not valid gives `#VALUE!` with the reason. The new function `shapeError` gives the reason. The compiler gives the same error through tier 1, and `emitModule` gives the reason.
